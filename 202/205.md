# メールサービス

### SMTPサーバ
- 送信プロセス
  - MUA -> MTA ->...-> MTA -> MDA -> popサーバ
  - この間はSMTP
  - 逐次DNSに問い合わせて対抗のpopサーバに到達する
- 受信プロセス
  - popサーバ -> MUA
  - この間はPOPもしくはIMAP

### 語句
- MUA ...メールクライアント
  - Mail User Agent
  - 送信/受信を実行するクライアント
  - Outlookやmailx
- MTA ...SMTPの転送を実行する
  - Mail Transfer Agent
  - postfix,sendmailなど
  - 「SMTPサーバ」と言われれば大体こいつ
- MDA...メールボックスにメールを格納する
  - Mail Delibary Agent
  - Dovecot,procmail,Courier Mail Serverなど

### メール受信形式
- mbox形式
  - /var/mail/{username}にすべて格納する
  - １つのファイルにすべてのメールを記載する
- Maildir形式
  - /home/{user}/ 配下に1メール1ファイル

## Postix
- MTA
- masterというプロセスの配下にプロセスを立てる構造
- 主要なプロセス
  - sendmail...sendmailの互換IF
  - smtpd...外部配送を処理する
  - pickup...maildropキューを監視し、内部配送
  - cleanup....incommingキューに入れ、qmgrに通知
  - qmgr...キュー内のメールを配送プログラムに譲渡
    - queue mangerの意味
  - nqmgr...より強い配送プログラムに譲渡
    - new queue managerの意味
  - bounce
    - バウンスメール(設定ミスで往来するメール)を処理
- Postfixの設定
  - `/etc/postfix/main.cf`...MTAの設定
  - `/etc/postfix/master.cf`...デーモンの設定
  
### /etc/postfix/main.cfの設定
- myhostname= 自ホスト名
- mydomain= ドメイン名
- mynetwork={ip}/{mask} メールを送信する送信元を指定
- reley_domain= メールを転送するドメインを指定
- inet_interface= NIFの指定
- onet_protocols= all/ipv4/ipv6設定
- mydestination...受信する宛先ドメイン
  - mynetworkに記載がない場合、そのメールは破棄
  - `$mydomain, localhost.$mydoamin`などを設定
- DNSの設定は書かない。linux本体のものを使用する
  - nsswitch.confすね

### 設定を出力する  postconf
`postconf`.../etc/postfix/main.cfを出力
`postconf -n`...デフォルトからの変更を表示
`postconf {q}`...qで設定から検索。完全一致のみ

### デーモンの詳細 /etc/postfix/master.cf
- topみたいな感じでプロセスが見える
- 各種プロセスの設定
  - service...サービス名smtp,qmgrなど
  - type...unix,inet,など
  - private...他のプロセスから隔離して実行。普通はy
  - unpriv...root権限以外で動かすか。通常はy
  - chroot...隔離環境で動かすか？
  - wakeup...自動起動の間隔。必要な時のみは「-」を設定
  - maxproc...同時に動かすプロセスすう
  - command...実際に実行するプログラム名

### メールリレーの規制
- DNSによって提示されるMTAサーバの連鎖
  - MTAを経由するたびにDNSを参照している
- 例
  - 送信元MUA...送信
  - 送信側内部MTA...社内のメール取りまとめ
  - 送信側外部リレーMTA...SPF,DKIMの署名チェック用
  - 受信側ゲートウェイ..スパムチェック用
  - 受信側MTA...ユーザが参照するメールサーバ
