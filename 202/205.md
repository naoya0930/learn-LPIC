# メールサービス

### SMTPサーバ
- 送信プロセス
  - MUA -> MTA ->...-> MTA -> MDA -> popサーバ
  - この間はSMTP
  - 逐次DNSに問い合わせて対抗のpopサーバに到達する
- 受信プロセス
  - popサーバ -> MUA
  - この間はPOPもしくはIMAP

### 語句
- MUA ...メールクライアント
  - Mail User Agent
  - 送信/受信を実行するクライアント
  - Outlookやmailx
- MTA ...SMTPの転送を実行する
  - Mail Transfer Agent
  - postfix,sendmailなど
  - 「SMTPサーバ」と言われれば大体こいつ
- MDA...メールボックスにメールを格納する
  - Mail Delibary Agent
  - Dovecot,procmail,Courier Mail Serverなど

### メール受信形式
- mbox形式
  - /var/mail/{username}にすべて格納する
  - １つのファイルにすべてのメールを記載する
- Maildir形式
  - /home/{user}/ 配下に1メール1ファイル

## Postix
- MTA
- masterというプロセスの配下にプロセスを立てる構造
- 主要なプロセス
  - sendmail...sendmailの互換IF
  - smtpd...外部配送を処理する
  - pickup...maildropキューを監視し、内部配送
  - cleanup....incommingキューに入れ、qmgrに通知
  - qmgr...キュー内のメールを配送プログラムに譲渡
    - queue mangerの意味
  - nqmgr...より強い配送プログラムに譲渡
    - new queue managerの意味
  - bounce
    - バウンスメール(設定ミスで往来するメール)を処理
- Postfixの設定
  - `/etc/postfix/main.cf`...MTAの設定
  - `/etc/postfix/master.cf`...デーモンの設定
  
### /etc/postfix/main.cfの設定
- myhostname= 自ホスト名
- mydomain= ドメイン名
- mynetwork={ip}/{mask} メールを送信する送信元を指定
- reley_domain=...メールを転送するドメインを指定
- inet_interface=...NIFの指定
- onet_protocols=...all/ipv4/ipv6設定
- mydestination=...受信する宛先ドメイン
  - mynetworkに記載がない場合、そのメールは破棄
  - `$mydomain, localhost.$mydoamin`などを設定
- DNSの設定は書かない。linux本体のものを使用する
  - nsswitch.confすね
- home_mailbox =...メールボックスの形式を選択


### 設定を出力する  postconf
`postconf`.../etc/postfix/main.cfを出力
`postconf -n`...デフォルトからの変更を表示
`postconf {q}`...qで設定から検索。完全一致のみ

### デーモンの詳細 /etc/postfix/master.cf
- topみたいな感じでプロセスが見える
- 各種プロセスの設定
  - service...サービス名smtp,qmgrなど
  - type...unix,inet,など
  - private...他のプロセスから隔離して実行。普通はy
  - unpriv...root権限以外で動かすか。通常はy
  - chroot...隔離環境で動かすか？
  - wakeup...自動起動の間隔。必要な時のみは「-」を設定
  - maxproc...同時に動かすプロセスすう
  - command...実際に実行するプログラム名

### メールリレーの規制
- DNSによって提示されるMTAサーバの連鎖
  - MTAを経由するたびにDNSを参照している
  - MXレコードにドメインのTLDのような階層は無い
- 例
  - 送信元MUA...送信
  - 送信側内部MTA...社内のメール取りまとめ
  - 送信側外部リレーMTA...SPF,DKIMの署名チェック用
    - ここで参照するのは、パブリックDNS
  - 受信側ゲートウェイ..スパムチェック用
  - 受信側MTA...ユーザが参照するメールサーバ
- オープンリレーを回避する手順
  - アウトバウンドのみを許可する
  - ドメインを指定してインバウンドを許可
  - 外部からのアウトバウンドのメールはすべて拒否
- 主要な許可パラメータ
  - `mydestination`
  - `mynetwork`

### エイリアスの設定
- `/etc/aliases`
- 転送以外にも色々できる
- 他のユーザにメールを転送する設定
  - `user1: user2.user3`
- 外部のメールアドレスに飛ばす
  - `user: user@admin.com`
- メールに書き込む
  - `user: /var/log/archive.log`
- メールを標準入力としてプログラムを実行する
  - `user: "| /home/work/sample.sh"`
- 他のファイルを読み込む
  - `user: :include:/home/work/maillist`

### エイリアスの設定ファイルを更新する
- `/etc/ailiases`
- `newaliases`コマンドを実行

### ユーザ単体でメールの転送
- `/home/user/.foward`にアドレスを記載
  - このファイルは、該当ユーザのみの書き込み権限に限定すること
- `sample@sample.com`
  
### SMTPサーバの操作
- MTAサーバ内にメールを一時保管する
  - これをメールキューと呼ぶ
- postfix.../var/spool/postfix/
- sendmail .../var/spool/mqueue/

### postfixスプールのメールを操作する
- 閲覧する
  - `postqueue -p`
  - `mailq`
- 強制的に送信する
  - `postqueue -f`
  - `postfix flush`
- キューの中のメールを削除
  - `postsuper -d {キューID}`
  - `postsuper -d ALL`

### postfixのメールキュー
- 以下は`/var/spool/postfix/[]`に存在
- maildrop/...ローカル配信に使用する
- incoming/...送受信処理中
- active/...配信待ちメール
- deferred/...送信に失敗したメールを保持

### MTAが受信したメール
- メールボックスに格納される
- sendmailの場合
  - `/var/spool/mail/{user}`
- postfixの場合
  - `/var/spool/mail/{user}`(mbox形式)
  - `/home/{user}/Maildir/`(maildir形式)

#### MTAがMDA(メールボックス)の配送先を指定
- 原則として、MDAはメールの読み手(クライアント)のユーザ情報を知っている
- postfixのみ
- home_mailbox = {mail_filename} (mbox形式)
- home_mailbox = Maildir/ (maildir形式)

## Dovcot MDAのメールフィルタリング言語 Sieve書式
- Dovcatで使用可能
- IMAP側で設定する
- フォルダ振り分け、転送、自動返信、破棄など
- 書式
  - `require["機能名"];`
  - `if [比較句]　{ 処理; }` 
- 機能名(ここで宣言しないと処理で使えない)
  - fileinto...指定したメールボックスへ
  - keep...デフォルトのメールボックスへ
  - discard...破棄する
  - reject...拒否する
  - redirect ...指定したメールアドレスに回送
  - stop...処理を停止する
  - vacation...自動返信する
- 条件
  - 比較句例
    - if header :contains "Subject" [お知らせ]{} 
      - ヘッダの件名にお知らせがある
    - if size :over 10M{}
      - サイズが10M以上ある
    - if address{}
      - 本件の内容を検索
    - if allof (...){}
      - 複数ある条件内の一つでも満たしている場合

### Procmailを設定する
- MDA(Mail Delivery Agent)の一種
- LMTP(Local Mail Transfer Protocol)によってMTAから起動/処理開始される
- ☆ LPIC 4.5以降から問われなくなった

#### DovecontでのPOPとIMAP
- よく使うプロトコル
- POP3...110
- IMAP4...143
- POP3S...993
- IMAPS...995
- 設定ファイルは`/etc/dovecot.conf`
- 設定ファイルを出力するには`doveconf`
  - `doveconf -n`でデフォルトからの差分
- 管理コマンドは `doveadm`
  - `doveadm reload`
    - 設定を再読み込み
  - `doveadm stop`
    - dovecotプロセスの停止
  - `doveadm log find`
    - ログファイルのパスを発見
  - `doveadm log test`
    - テストログメッセージを生成
  - `doveadm pw`
    - パスワードのハッシュ値を生成

#### 設定ファイルの主要な項目
- /etc/dovecot.conf
  - auth_mechanisms...認証メカニズム
  - mail_location...メールの配送場所/配送形式
  - ssl...SSL/TLSを有効するか？
  - ssl_cert...サーバ証明書ファイル
  - ssl_key...サーバ鍵ファイル
